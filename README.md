# DB-LAB-PROJECT-
Database Management System for Departmental Store
# Description
The Departmental Store Database Management System is a database project designed to store, manage, and organize all the information related to a departmental store. The system will maintain records of products, customers, suppliers, sales, employees, and inventory in a structured database. The main purpose of this project is to replace manual record-keeping with a computerized database system that ensures data accuracy, fast access, and efficient management of store operations.
